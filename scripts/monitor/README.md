# مراقبة موقع عرب راسلنج

فيه **طبقتين**، وكل طبقة بتعمل حاجة مختلفة. الطبقة الأولى هي اللي اخترتها: **بدون أي ذكاء
اصطناعي**، فمستحيل «تهلوس» أو تدّعي شغل معملتهوش.

| الطبقة | بتعمل إيه | بتشتغل إزاي | الحالة |
| --- | --- | --- | --- |
| **١. المراقب التقني** (`watch.ts`) | صفحة واقعة · بوت الأخبار واقف · نشر قديم · تشغيل فشل · اختبار فشل · ريبو متأخر | حساب صريح في الكود | ✅ جاهز |
| ٢. المراجعة اللغوية (`site-guard.md`) | أخطاء الإملاء والنحو والمثنى وأسماء المصارعين — **اقتراحات بس** | موديل مجاني | مقفول لحد ما تطلب |

> **ليه الطبقتين منفصلين؟** لأن الموديل المجاني جرّبناه فطلع **بيقول إنه عمل شغل وهو معملوش**.
> الحاجات اللي لازم تكون مضبوطة ١٠٠٪ (الموقع واقف؟ الخبر نزل؟) سيبناها للكود، مش للموديل.

# الطبقة ١: المراقب التقني

## بيشوف إيه؟

| الفحص | بيعتبره عطل لما… |
| --- | --- |
| الصفحات الحية (`/`, `/news/`, `/sitemap.xml`, `/robots.txt`, `/build.json`) | صفحة مش بتفتح، أو ردت كود غلط، أو خدت أكتر من ٨ ثواني |
| **بوت الأخبار** (`watcher-state.json`) | البوت متقفّل، أو نبضه واقف أكتر من ٢٠ دقيقة، أو استهلاكه قرب الحد اليومي |
| النشر | الموقع الحي واقف على نسخة أقدم من `main` بأكتر من ٤٠ دقيقة |
| الأخبار | مفيش خبر جديد من ٦ ساعات |
| تشغيلات GitHub | تشغيل فشل خلال آخر ٦ ساعات |
| الاختبارات والبناء | `npm run test:publishing` أو `npm run build` فشل |
| الريبو المحلي | متأخر عن GitHub، أو لسه فيه شغل مش مرفوع |

**كل الأنواع دي اتصحّحت بعد فحص حقيقي على الموقع الحي** — والفحص الأول طلع إنذار كاذب
(`/health`) لأن الـworker عندك cron بس ومش موصول بالدومين، فاتصلّح وبقى بيقرا **نبض البوت
الحقيقي** بدل صفحة مالهاش وجود.

## المشاكل بتتتبّع، مش بتتكرر

كل عطل له مفتاح ثابت (`page:/news/`, `worker:stalled`…)، فالتقرير بيفرّق بين:

- **جديد** — ظهر أول مرة في اللفة دي (ده اللي بيوصلك تنبيه)
- **لسه موجود** — ومعاه من امتى (`since`)، فتعرف العطل قاعد بقاله قد إيه
- **اتصلّح** — كان موجود وبقى تمام

## الإصلاح التلقائي

`--fix` بيعمل **حاجتين محليين آمنين بس**: تحديث مراجع GitHub (`git fetch --prune`)،
وتنظيف. **مفيش أي إصلاح بيلمس الموقع الحي** — لسه محتاج إذنك، ومكتوب كده صراحة في الكود.

## التشغيل

```bash
npx tsx scripts/monitor/watch.ts                 # لفة واحدة
npx tsx scripts/monitor/watch.ts --with-tests    # + الاختبارات والبناء
npx tsx scripts/monitor/watch.ts --daemon        # يفضل شغّال (كل ٥ دقايق)
npx tsx scripts/monitor/watch.ts --json          # مخرجات للماكينات
npx tsx scripts/monitor/watch.ts --fix           # + الإصلاحات المحلية الآمنة

bash scripts/monitor/install-macos.sh                # خدمة على الماك — كل ساعة الدقيقة ٥
bash scripts/monitor/install-macos.sh --every 5      # أو كل ٥ دقايق
bash scripts/monitor/install-macos.sh --with-tests   # ومعاه الاختبارات والبناء
bash scripts/monitor/install-macos.sh --status
bash scripts/monitor/install-macos.sh --uninstall

npx tsx --test tests/monitor-checks.test.mts tests/monitor.test.mts   # الاختبارات
```

كود الخروج `1` لو فيه عطل حقيقي — وده اللي بيخلّي GitHub يبعتلك إيميل من غير أي إعداد.

## ٢٤/٧ حقيقي (بره جهازك)

`.github/workflows/site-watch.yml` — كل ساعة في الدقيقة ٥، على سيرفرات GitHub:

- **مابيكتبش ولا ملف في المستودع.** مفيش `git push` ولا كوميت ولا مفاتيح سرية.
- بيقرا، بيفحص، بيرفع التقرير كـartifact، **وبيفشل** لو فيه عطل → وصلّك إيميل.

مقفول لحد ما تفتحه بنفسك:

```bash
gh variable set ARW_WATCH_ENABLED -R m7mdibrahimo/arw-site --body true    # تشغيل
gh variable delete ARW_WATCH_ENABLED -R m7mdibrahimo/arw-site             # إيقاف
gh workflow run site-watch -R m7mdibrahimo/arw-site                       # تجربة بإيدك
```

> ماك مقفول؟ مفيش مشكلة. المراقب ده بيشتغل على سيرفرات جيتهب.

## التنبيه (اختياري)

لو عايز تنبيه على تيليجرام كمان، حدّد المتغيّرين دول وهما بس:

```bash
export TELEGRAM_BOT_TOKEN=...
export ARW_ALERT_CHAT_ID=...
```

من غيرهم، التنبيه هو فشل التشغيل (إيميل GitHub) — وده كفاية ومجاني.

## الملفات

| الملف | دوره |
| --- | --- |
| `scripts/monitor/checks.ts` | **المنطق**: كل الأحكام. دوال خالصة — مفيش شبكة، مفيش ملفات، مفيش موديل |
| `scripts/monitor/watch.ts` | **التشغيل**: بيقرا، بيحكم، بيكتب `reports/guard/`، وبيبلّغ |
| `scripts/monitor/config.json` | الإعدادات (الحدود والصفحات) + مكان قائمتك المخصوصة |
| `scripts/monitor/install-macos.sh` | خدمة `launchd` (احتياطي محلي) |
| `.github/workflows/site-watch.yml` | التشغيل ٢٤/٧ على سيرفرات GitHub |
| `reports/guard/` | `status.json` · `monitor.log` · `heartbeat.json` — معزولة عن git |
| `tests/monitor-checks.test.mts` | اختبارات كل حكم (عطل حقيقي / إنذار كاذب) |

## تعدّل الحدود من غير كود

```jsonc
{
  "site":  { "pages": ["/", "/news/", "/sitemap.xml", "/robots.txt", "/build.json"], "slowMs": 8000 },
  "worker": { "maxIdleMin": 20, "apiWarnAt": 0 },   // apiWarnAt: حط الحد اليومي لما تعرفه
  "feed":  { "maxAgeHours": 6 },
  "deploy": { "maxLagMin": 40 },
  "ci":    { "windowHours": 6 }
}
```

`"custom"` — حط فيها أي حاجة مخصوصة عايزها تتراقب كل لفة.

# الطبقة ٢: المراجعة اللغوية (اختيارية، مقفولة)

`.opencode/agents/site-guard.md` + `scripts/monitor/run-round.sh` + `.github/workflows/hourly-guard.yml`.

**القاعدة الأساسية: بيقترح، مش بيعدّل.** الكتابة مقفولة على كل الملفات **إلا**
`reports/**` و `INCIDENTS.md` — يعني حتى لو حاول يعدّل خبر، الأداة ترفض.

- ممنوع يغيّر أي حاجة الزائر بيشوفها · ممنوع نشر على السوشيال · ممنوع حذف محتوى
- ممنوع لمس المفاتيح والأسرار · ممنوع تشغيل بوت الكتابة · ممنوع `push`/`commit`/`reset`/`sudo`/`rm -rf`

الاقتراحات بتتكتب في `reports/guard/suggestions.md` بالشكل ده:

```markdown
## ١ — content/news/<الملف>
- **الغلطة:** `رومان رينجز`
- **الصح:** `رومان رينز`
- **السبب:** اسم مصارع — القاموس ينص على «رومان رينز»
```

كل القواعد دي متختبرة في `tests/monitor.test.mts` — لو حد شالها، الاختبار بيفشل.

### التحذير الصريح

الموديل المجاني **اتقفل متعمّد** لأنه في التجربة:

- ✅ **رفض** يعدّل خبر (المحتوى اتحمى فعلاً — اتحققنا من الملفات)
- ✅ كتب التقارير بنجاح
- ❌ **قال «عملت الملف وكتبت فيه» والملف مكانش موجود خالص**

يعني مناسبه اقتراحات بتتراجع بعينك، **مش** يشتغل لوحده على موقع أخبار. لو عايز مراجعة
لغوية موثوقة، الحل موديل أقوى — والفصل الحالي بيخلّيك تقرر ده لوحدك من غير أي خطر.

## حاجات مالهاش علاقة بتشغيلك القديم

- مفيش أي ملف من ملفاتك القديمة اتغيّر (لا `package.json` ولا `_data` ولا قوالب).
- مفيش أي حاجة من اللي بتشتغل دلوقتي اتقفلت. المراقبين بيقروا بس.
- فيه دليلين: `hourly-guard.yml` (اللغوي) و `site-watch.yml` (التقني) — الاتنين مقفولين،
  والاتنين مايشتغلوش غير لما تفتحهم بمفتاح.
